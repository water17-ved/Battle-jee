# JEE Battle Royale Tracker — New Firebase Web App

Complete deployable PWA bundle based on the latest supplied tracker HTML, including the recent home-screen and haptic changes.

## Files
- `index.html` — complete application
- `manifest.json` — PWA manifest, install metadata and shortcuts
- `sw.js` — service worker for the PWA app shell/offline caching
- `icon-192.png` — 192px install icon
- `icon-512.png` — 512px install icon
- `.nojekyll` — GitHub Pages compatibility marker
